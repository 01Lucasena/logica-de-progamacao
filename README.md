🧠 Desafios Diários de Lógica de Programação (JavaScript)

Este repositório reúne uma coleção de desafios de programação, publicados diariamente, com o objetivo de treinar e aprimorar o raciocínio lógico e as habilidades de resolução de problemas usando JavaScript.

A ideia é simples: todos os dias um novo desafio é adicionado, cobrindo desde conceitos básicos (loops, condicionais, funções, arrays) até problemas mais avançados (estruturas de dados, algoritmos, recursão, manipulação assíncrona). A proposta é praticar constância — um pouco de lógica por dia constrói uma base sólida com o tempo.

🛠️ Tecnologias
JavaScript (Node.js)
📁 Estrutura

Cada desafio fica em sua própria pasta, organizada por data, contendo:

README.md — enunciado do problema
solucao.js — minha solução em JavaScript
Testes ou exemplos de entrada/saída, quando aplicável
/2026-08-08-fizzbuzz-modificado
  ├── README.md
  └── solucao.js
🎯 Objetivos
Praticar lógica de programação diariamente
Aprofundar o domínio de JavaScript
Documentar o processo de aprendizado
Criar um histórico visível de evolução ao longo do tempo
▶️ Como rodar as soluções
bash
node caminho/para/solucao.js
🚀 Como usar

Sinta-se à vontade para clonar o repositório, tentar resolver os desafios por conta própria antes de olhar as soluções, e abrir issues ou PRs com sugestões de novos desafios ou soluções alternativas.
